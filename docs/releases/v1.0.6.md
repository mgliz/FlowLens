# FlowLens 1.0.6

**English** | [简体中文](v1.0.6.zh-CN.md)

FlowLens 1.0.6 adds GitHub updates and refines the desktop interface, including custom-period editing and complete light/dark calendar styling. This is a stable release, without the test-build badge.

## What's new

- **GitHub updates:** check the official `mgliz/FlowLens` Releases from About, or automatically at most once per day at startup. Startup checks can be disabled in Settings. A fallback handles anonymous API rate limits without a GitHub token.
- **Verified installation:** downloads are checked against SHA-256 and the executable version. The app saves its data and exits normally before replacement, preserves settings/history, and keeps an EXE backup. Failed startup restores the backup for a manual restart.
- **Compact interface:** the complete custom-period summary sits beside the toolbar, controls wrap when space is limited, statistics have less empty space, and process names have comfortable horizontal margins.
- **Consistent time controls:** the floating date/hour editor and calendars use the same fade transition as other dropdowns. Cancel, Escape, and outside dismissal restore the applied period. Corrected invalid date input no longer needs an extra Apply click.
- **Theme and display fixes:** readable light/dark calendar day, month and year views; themed hover tooltips; correct adapter names in Settings; no persistent toolbar outlines; and a compact update panel in About.
- **Language navigation:** documentation defaults to English, with separate Simplified Chinese pages linked from each entry point.

## Download and upgrade

Download [FlowLens-1.0.6-win-x64.zip](https://github.com/mgliz/FlowLens/releases/download/v1.0.6/FlowLens-1.0.6-win-x64.zip), extract it, and run `FlowLens.exe` as administrator. The package supports Windows 10/11 x64 and **includes the .NET runtime**; no separate .NET installation is required. Checksums are available in [SHA256SUMS.txt](https://github.com/mgliz/FlowLens/releases/download/v1.0.6/SHA256SUMS.txt).

Users of 1.0.5 should download this package manually. A preview build with the updater can find this release through **About → Check for updates**. For a manual upgrade, exit the old app from its tray menu before starting the new EXE. Settings and traffic history stay in `%APPDATA%\FlowLens`.

## History compatibility

This release keeps the history format introduced in 1.0.5. New samples use local hourly buckets; older daily totals are included only when the entire day is selected. Existing daily records cannot be reconstructed into hourly detail. Statistics accumulate while FlowLens is running; this version does not retrospectively change earlier traffic records.
