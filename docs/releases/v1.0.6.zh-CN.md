# FlowLens 1.0.6

[English](v1.0.6.md) | **简体中文**

FlowLens 1.0.6 新增 GitHub 更新功能，并完善桌面界面、自选时段编辑及日历的深浅色主题。这是正式版本，不再显示测试版标识。

## 本次更新

- **GitHub 更新：**可在“关于”中检查 `mgliz/FlowLens` 的官方 Release，也可在启动时每天自动检查至多一次。自动检查可在设置中关闭；匿名 API 达到限额时使用备用查询方式，无需 GitHub Token。
- **校验后安装：**下载后校验 SHA-256 和程序版本，保存数据并正常退出后再替换程序。保留设置、历史记录和旧 EXE 备份；新版本启动失败时恢复备份，随后可手动重启。
- **紧凑的界面：**完整自选时段放在顶部工具栏附近，空间不足时自动换行；减少统计区的空白，并为进程名称增加水平留白。
- **统一的时间控件：**日期和小时编辑浮层、日历与现有下拉菜单使用一致的淡入过渡。取消、按 Escape 或点击浮层外部会恢复已应用的时段；纠正无效日期后无需多点一次“应用”。
- **主题与显示修复：**完善日历日期、月份和年份视图的深浅色显示；悬浮提示跟随主题；设置中正确显示网卡名称；工具栏按钮不再残留描边；关于窗口的更新区更紧凑。
- **语言切换：**文档默认使用英文，通过入口链接切换至独立的简体中文页面。

## 下载与升级

下载 [FlowLens-1.0.6-win-x64.zip](https://github.com/mgliz/FlowLens/releases/download/v1.0.6/FlowLens-1.0.6-win-x64.zip)，解压后以管理员身份运行 `FlowLens.exe`。支持 Windows 10/11 x64，**已包含 .NET 运行时**，无需另行安装。校验文件见 [SHA256SUMS.txt](https://github.com/mgliz/FlowLens/releases/download/v1.0.6/SHA256SUMS.txt)。

1.0.5 用户需要手动下载此包；带有更新功能的测试版可通过 **关于 → 检查更新** 获取本次正式版。手动升级时，先从托盘菜单退出旧程序，再运行新的 EXE。设置和流量历史继续保存在 `%APPDATA%\FlowLens`。

## 历史兼容

本版继续使用 1.0.5 引入的历史格式。新采样按本地小时保存；旧日统计仅在所选时段完整包含该天时计入，无法还原成小时明细。FlowLens 只在运行期间累计流量，本次升级不会回溯改写此前的流量记录。
